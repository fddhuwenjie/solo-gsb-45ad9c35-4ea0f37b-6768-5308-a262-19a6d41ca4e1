反事实干预沙盘

勾选多个被阻止事件（干预点）并指定观察目标，系统按拓扑顺序推演 prevented / still_active。只读，不产生 changeset 或版本。 事件触发模式：ANY=任一前因发生即触发；ALL=全部前因均发生才触发；无前因的事件默认发生。

选择目标并勾选干预点后即时推演；未提交工作图即时生效。

可复算复盘结论包

从当前查看的版本选择一个事件，导出含 SHA-256 摘要的自包含结论包 （事件 + 全部因果祖先 + 关联证据 + 版本元数据 + 时间窗与证据审查结果）。 上传结论包可只读核验：先校验摘要，再仅凭包内数据重建 DAG 重算比对。

存在未提交修改：导出基于已提交版本，未提交的新事件不可导出。

导出与核验均为只读：不写库、不生成版本、不改变工作图。
